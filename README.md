# 瞬間ループ
制作者：HAIsan


## 概要
指定した開始位置から再生間隔の分だけ再生を回数だけ繰り返した後通常の再生を行うようにする音声エフェクトを追加するプラグインです

## 使用方法
音声エフェクト(またはプラグイン)→瞬間ループ　で追加  
  
開始位置で音声のループスタート位置を調整、ここで音声はじめの無音部分などをカットできる  
再生間隔でループするときに流す長さを指定  
回数で何回鳴らすかを指定。0なら無限、2回なら1回再生された後再生し直される。n回ならn-1回再生された後再生され直される。  
余白の秒数だけループ再生の間隔を指定
